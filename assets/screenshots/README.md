# 截图素材

市场详情页会按 `screenshots.json` 里声明的顺序展示这里面的图片。

## 放置约定

- 文件名：`01-panel.png`、`02-group-switch.png` …（数字前缀控制顺序）
- 格式：PNG（也可 JPG/WebP）
- 建议尺寸：宽 1200–1600px，比例 16:10 或 16:9；正方形也可（界面细节多，横向更清楚）
- 内容：**真实界面截图**，不要示意图

## 至少建议截这两张

1. **面板全貌**（首页左侧栏点图标后）：标题、地址、协议下拉、API Key 状态、分组切换、诊断行
2. **分组切换生效**：切换前后的模型列表或倍率变化（能体现「就地切组」这个卖点）

## 敏感信息

截图前请确认：

- API Key 输入框是空的（插件 write-only，本就不回显，但仍请检查）
- 中转站地址若是私人域名，可按需遮挡；内置预设地址是公开的，无需处理
- 不要在截图里露出其它插件的密钥或会话内容

## 加完怎么生效

1. 把图片放进本目录
2. 在仓库根 `screenshots.json` 里按顺序列出
3. commit + push —— 市场下次构建自动读取，**不需要再提 PR**
